* Architecture

The full airflow capability bundle consists of:

| File                        | Role                                                        |
|-----------------------------+-------------------------------------------------------------|
| =airflow-sbom.pcs=          | apt + pip install into =/bisos/venv/py3/asc=                |
| =airflow-db-sysd.pcs=       | oneshot unit: runs =airflow db migrate=                     |
| =airflow-webserver-sysd.pcs= | =airflow api-server --port 24006= (banna port)             |
| =airflow-scheduler-sysd.pcs= | =airflow scheduler=                                        |
| =airflow-triggerer-sysd.pcs= | =airflow triggerer=                                        |
| =airflow-here-dns.pcs=      | adds =airflow.here= to =/etc/hosts= via =capDns=            |
| =airflow-wvd.pcs=           | NGINX virtual host for =airflow.here= via =capWebVd=        |
| =airflow-wvds-np-cbs.pcs=   | CBS bundling all of the above                               |

=airflow-wvd.pcs= uses IP from =socket.gethostbyname('airflow.here')= and port
from =bisos.banna= (24006). It uses the =configFile.ConfigFile= pattern
(=configFileStdout= / =configFileUpdate= with =--cls=configFile_nginxVd=).

* Key Design Decisions

- *=airflow db migrate= as oneshot systemd unit* (=airflow-db-sysd.pcs=): =Type=oneshot=
  + =RemainAfterExit=yes=. The three service units declare =Requires=airflow-db.service=
  and =After=airflow-db.service= — systemd enforces ordering and records completion
  in the journal.
- *=airflow webserver= is removed in Airflow 3.x*: replaced with =airflow api-server=
  in =airflow-webserver-sysd.pcs=.
- *Port from banna*: =airflow= port is =24006= (=bisos.banna.tcpPorts=), not hardcoded.
- *IP from =/etc/hosts=*: =airflow-wvd.pcs= resolves =airflow.here= via
  =socket.gethostbyname()= rather than hardcoding =127.0.0.1=.
- *=configFile= pattern for NGINX*: =capWebVd= uses =ConfigFile_nginxVd= subclass;
  =configFileStdout= previews, =configFileUpdate= writes as root.
- *CBS =assemble=None=*: db migration is handled by the dedicated oneshot unit,
  not the CBS assemble step.
